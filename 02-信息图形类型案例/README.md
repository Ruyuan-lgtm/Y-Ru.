# 02 信息图形类型案例

本目录根据案例图的视觉叙事和编码方式，持续整理三类常见信息图形。说明文档应随着新案例增加而更新原则、方法、适用场景和反例。

## 案例类型

1. [混合型信息图形（Mixed Charts）](./混合型信息图形/说明文档.md)
2. [文字型/列表型信息图形（Informational / List Infographics）](./文字型列表型信息图形/说明文档.md)
3. [时间轴型信息图形（Timeline Infographics）](./时间轴型信息图形/说明文档.md)

## 跨类型基础设计方法标签

- **ISOTYPE**：基础设计方法标签，不属于信息图形类型。
- 它可与时间轴型、混合型、文字/列表型、地理型等类型组合使用。
- 在案例报告的“信息图形类型学分类”或“视觉编码”部分写入 ISOTYPE，同时保留主要信息图形类型。
- 专题说明：[ISOTYPE 专题标签说明文档](./ISOTYPE/说明文档.md)。

## 记录规范

每个类型目录中的说明文档应记录：数据结构、借用的统计图形与计算、视觉编码、信息架构、视觉叙事、案例来源、适用边界和待验证问题。图片文件可后续加入同目录，并在文档中注明来源与许可。
