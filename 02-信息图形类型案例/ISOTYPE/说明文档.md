# ISOTYPE 专题标签

> 定位：基础设计方法标签，不是信息图形类型。

ISOTYPE（International System Of Typographic Picture Education）是一套以图形符号、重复计数、统一比例和公共解释为核心的视觉教育与信息设计方法。它可以嵌入时间轴、混合型、文字/列表型和地理型信息图，因此在本知识库中作为跨类型标签使用。

## 一、标签定位

- **类型学位置**：ISOTYPE 不与编年型、层级型、时间轴型等并列；这些名称描述信息图形的组织逻辑或叙事形式，ISOTYPE 描述底层的符号化设计方法。
- **标签写法**：在案例报告的“信息图形类型学分类”或“视觉编码”部分加入 `ISOTYPE`，同时保留案例所属的主要类型。
- **组合方式**：可使用 `ISOTYPE + 时间轴型`、`ISOTYPE + 混合型`、`ISOTYPE + 地理图形` 等组合标签。

## 二、核心设计原则

1. 一符号一单位：同类对象使用统一符号，符号数量对应数量单位。
2. 重复而非变形：优先用重复符号表达数量，避免只靠符号大小表达精确计量。
3. 明确图例与尺度：说明一个符号代表多少人、件、吨或其他单位；半符号需说明近似规则。
4. 统一形态：保持符号轮廓、朝向、比例和间距一致。
5. 先比较后装饰：装饰不能改变计数、类别和比较关系。
6. 适度聚合：数据过密时按地区、阶段或主题聚合，并说明聚合规则。

## 三、数据与统计要求

ISOTYPE 不是统计图形本身，但可承载计数、比例、构成和比较。案例应记录原始单位、符号代表的数量、分组规则、换算方法、四舍五入方式、缺失值与不确定性。若类别单位不同，应先标准化。

它可以与柱形图、点图、时间轴、地图分级、流程节点或文字列表组合。组合时分别说明统计图形承担的计算关系，以及 ISOTYPE 符号承担的解释和识别关系。

## 四、视觉编码

符号应可识别、可重复且语义稳定；数量主要由符号个数、符号组或统一比例表达；位置与间距使用规则网格；色彩用于类别、阶段或强调，不应成为唯一数量编码；标题给出结论，图例解释单位，注释补充来源、时间范围和限制。

## 五、信息架构与视觉叙事

推荐结构为“主题与结论 → 单位和图例 → 分组比较 → 符号化数据 → 来源与限制”。读者先理解比较对象和计量单位，再读取符号数量，最后查看注释。跨时间或空间的案例需明确时间尺度、地理范围和聚合方法。

## 六、案例记录模板

新增案例时记录：主要信息图形类型、符号单位、重复计数、图例、半符号或标准化规则、统计关系、视觉检查、数据来源、时间范围、缺失值和适用限制。
