# 信息图知识库

本仓库用于系统整理信息图形的类型学、视觉编码、信息框架与叙事方法。

- [01-编年型信息图](./01-编年型信息图/)
- [02-层级型信息图](./02-层级型信息图/)
- [03-关系型信息图](./03-关系型信息图/)
- [04-流程型信息图](./04-流程型信息图/)

## 使用方式
每类目录中的“概念及说明.md”用于持续维护该类型的定义、适用场景与设计检查点；案例报告按照模板记录数据结构、统计图形应用、视觉编码、信息框架、叙事框架和信息图形类型学分类。
示例图目录先提供占位说明，后续可替换为实际图片文件并在报告中补充来源与许可信息。
